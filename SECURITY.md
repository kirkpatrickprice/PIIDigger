# Security Policy

PIIDigger scans files for PII (card numbers, emails, and other sensitive data). If you find a security vulnerability — especially anything that could cause sensitive data to be logged, written insecurely, or exposed to an unintended party — please **do not** open a public issue.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting instead: go to the [Security tab](https://github.com/kirkpatrickprice/PIIDigger/security) and click **Report a vulnerability**, or go directly to [github.com/kirkpatrickprice/PIIDigger/security/advisories/new](https://github.com/kirkpatrickprice/PIIDigger/security/advisories/new).

This creates a private draft advisory visible only to the maintainer until a fix is ready, so details don't leak before a patch is available.

## Supported branches

- `main` — v2.0 release baseline. Continued active development.
